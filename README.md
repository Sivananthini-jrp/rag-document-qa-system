## RAG Document Question Answering System

A document-based question-answering application built using Python, LlamaIndex, Streamlit, vector retrieval, and large language models.

### Features
- Document loading and indexing
- Retrieval-augmented question answering
- Configurable embedding models and retrieval parameters
- Interactive chatbot interface
